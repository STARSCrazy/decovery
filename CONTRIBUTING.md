# Contributing

Thanks for your interest in decovery.

- Open an issue before larger changes, especially new capabilities, plugins or changes to on-disk formats and the
  plugin protocol. Those need an ADR (`docs/adr/`).
- Keep pull requests focused. Include tests; public tests must not depend on proprietary binaries.
- AI-assisted contributions are welcome. A human author is responsible for every change and confirms it was
  verified (tests run, behaviour checked).
- Code, names and docs are English. Formatting: `cargo fmt`; lints: `cargo clippy -- -D warnings`.
- By contributing you agree that your work is licensed under `Apache-2.0 OR MIT`.
